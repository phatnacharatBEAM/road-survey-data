แปลง .shp เป็น GeoJSON

ทำงานในเครื่องคุณทั้งหมด ไฟล์ไม่ถูกส่งไปที่ไหน ไม่ต้องเข้าสู่ระบบ

ขั้นต่อไป

  1. อัปโหลดไฟล์ที่ดาวน์โหลดไว้เข้าโฟลเดอร์ geojson ใน repo GitHub (Add file → Upload files → Commit)
  2. เสร็จแล้ว ไม่ต้องแก้ไฟล์อื่น รอสักครู่ (ไม่เกิน 5 นาที) โครงการจะขึ้นในช่องเลือกโครงการของหน้าแผนที่เอง ชื่อที่แสดงมาจากชื่อไฟล์
อยากตั้งชื่อที่แสดงเป็นภาษาไทย (ไม่บังคับ)

เพิ่มบรรทัดนี้ในไฟล์ projects.json (ใส่เครื่องหมายจุลภาคคั่นรายการ) แล้วแก้ค่า name เป็นชื่อที่ต้องการ


      
    

  

  
ชื่อไฟล์และรหัสโครงการใช้ได้เฉพาะ A-Z a-z 0-9 _ - · รองรับพิกัด WGS84 (EPSG:4326) และ UTM WGS84 (เช่น EPSG:32647/32648) ที่มีไฟล์ .prj ร่วมด้วย · ระบบพิกัดอื่น (เช่น Indian 1975) ให้ส่งออกเป็น EPSG:4326 ใน QGIS ก่อน · ไฟล์ต้องเป็นเส้น (Polyline)
